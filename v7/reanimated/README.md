# React Native Reanimated source

The explorer hosts the complete official React Native Reanimated showcase source
from the [v4.5.3 release](https://github.com/software-mansion/react-native-reanimated/tree/4.5.3).

- Release commit: `4da1f397d464a1e09823fa70dd8b02100a6ab12b`
- Upstream folder: `apps/common-app/src`
- Source package: `react-native-reanimated@4.5.3`

`source/official/` is the copied release source. The local host only provides
the independent navigation and providers needed to run it inside Expo Router.
Metro resolves the upstream `@/` imports relative to this source directory.
