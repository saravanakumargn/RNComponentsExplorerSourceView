# Tamagui source

The Tamagui explorer uses the direct, unmodified kitchen-sink and demo source
from the official [Tamagui v2.5.1 release](https://github.com/tamagui/tamagui/tree/v2.5.1).

- Archive SHA-256: `0186a8559632886948f4bf3fea17d95ceb6d9888e121daf22a82279be26ff81f`
- Upstream folders: `code/kitchen-sink-shared` and `code/demos`

`source/official/` contains the release files. The only local code is the Expo
Router adapter that hosts Tamagui's original `HomeScreen` and `DemoScreen`.
