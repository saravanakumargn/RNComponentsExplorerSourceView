# React Native NetInfo source

The explorer hosts the official React Native NetInfo example source from the
[v12.0.1 release](https://github.com/react-native-netinfo/react-native-netinfo/tree/v12.0.1).

- Release commit: `d9923d2c15137b36bdc763d0d1f9dd118a4a1ca1`
- Upstream folder: `example/`
- Source package: `@react-native-community/netinfo@12.0.1`

`source/official/` contains the example screens from that release. The local
host removes the standalone app registration and E2E deep-link test harness,
then exports the example UI for Expo Router to render inside the explorer.
